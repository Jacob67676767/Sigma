# Sigma Flappy Bird

A lightweight Flappy Bird clone written in Python using [pygame](https://www.pygame.org/).

## Getting started

1. Create a virtual environment (optional but recommended).
2. Install the dependency:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the game:

   ```bash
   python flappy_bird.py
   ```

Press <kbd>SPACE</kbd> (or the up arrow) to flap. Avoid the pipes to earn points. When you collide
with a pipe or the ground/ceiling, press <kbd>SPACE</kbd> to restart.
